PERKONS MOD MATRIX DESKTOP FOR LINUX (x86_64): NOT TESTED

This Linux version is built automatically, but nobody has tried it on a Linux computer yet.
If anything doesn't work, please open an issue, with what you did, what happened and your
Linux distribution and version:

    https://github.com/remixed123/modmatrix-desktop/issues

The log file helps: ~/.local/share/perkons-mod-matrix/launcher.log

RUN IT

    cd perkons-mod-matrix
    ./perkons-mod-matrix

It opens in your default web browser (there's no window of its own). Keep the terminal
open while you use it; press Ctrl-C there, or close the terminal, to quit. The first start
needs an internet connection.

It needs a 64-bit Intel or AMD PC with a recent Linux (glibc 2.35 or later: Ubuntu 22.04,
Debian 12, Fedora 36 or later, and similar).

Its data (downloads, settings) is in ~/.local/share/perkons-mod-matrix/. To uninstall, delete
this folder and that one.
