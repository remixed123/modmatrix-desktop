**New in 0.3.0: a new name and an icon.** The app is now called **Perkons Mod Matrix Desktop**
and has its own icon.

**In 0.2.0: user guides.** A **USER GUIDES** tab next to the Mod Matrix shows every mod's
and engine's guide, from all mod repos, without loading any firmware.

The Pērkons HD-01 Mod Matrix by kiteless, packaged as a desktop app by remixed123: open
it, drop in your own official firmware image, tick mods, build, download the modded image.
No Git, Python, compiler or terminal needed. The first start needs an internet connection.

* Mac (Apple Silicon, macOS 11+): `ModMatrixDesktop-macOS.dmg`. Open it and drag the app
  to Applications.
* Windows (10 or 11, 64-bit): `ModMatrixDesktop-Windows.zip`. Extract it and run
  `Perkons Mod Matrix Desktop.exe`. Not signed: if Windows warns, choose "More info", then "Run anyway".

Install and use: see the [README](https://github.com/remixed123/modmatrix-desktop#readme).

Unofficial. Not affiliated with or endorsed by Erica Synths. Modded firmware is flashed
entirely at your own risk. Keep the official firmware and reflash it before any service.

The `arm-gnu-toolchain-src-snapshot-*.tar.xz` file is the source of the bundled GPL toolchain.
